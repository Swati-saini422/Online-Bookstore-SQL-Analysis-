# 📚 Online Bookstore SQL Analysis

## 📌 Project Overview

This project analyzes an online bookstore dataset using **PostgreSQL and SQL**. The dataset contains information about books, customers, and orders.

The main goal of this project is to analyze **sales, customer purchases, revenue, book genres, authors, and inventory** using SQL queries.

## 🛠️ Tools & Technologies

* PostgreSQL
* SQL
* CSV Files

## 📂 Dataset

The project contains three CSV files:

* **Books.csv** – Book details such as title, author, genre, price, and stock.
* **Customers.csv** – Customer information such as name, email, city, and country.
* **Orders.csv** – Order information such as order date, quantity, and total amount.

## 📊 Analysis Performed

The project includes SQL queries to analyze:

* Books by genre
* Books published after a specific year
* Customer information by country
* Orders by date
* Total book stock
* Most expensive and lowest-stock books
* Total revenue
* Books sold by genre
* Average price by genre
* Customers with multiple orders
* Most frequently ordered books
* Sales by author
* Customer spending
* Inventory and remaining stock
